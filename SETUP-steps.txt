香港蟲害管理新聞情報中心 — 重新安裝步驟
================================================

A. 刪除舊 repository
   1. 打開 https://github.com/peterusingai1222-cloud/hk-pest-news
   2. Settings → 拉到最底 Danger Zone → Delete this repository → 按指示確認

B. 開新 repository
   1. 打開 https://github.com/new
   2. Repository name：hk-pest-news
   3. 揀 Public；唔好剔 Add a README file
   4. Create repository

C. 上載檔案（用 Codespaces）
   1. 喺新 repository 頁面：Code（綠色掣）→ Codespaces → Create codespace on main
   2. Windows 檔案總管 → 檢視 → 剔「隱藏的項目」
   3. 打開解壓後嘅 hk-pest-news 資料夾，Ctrl+A 揀晒入面所有嘢（要見到 .github）
   4. 拖入 Codespaces 左邊 Explorer
   5. 喺下面 Terminal 打：
      git add -A && git commit -m "安裝" && git push
      （見到 main -> main 即成功；如問 branch，改打：git push -u origin main）

D. GitHub 設定
   1. Settings → Actions → General → Workflow permissions
      → 揀 Read and write permissions → Save
   2. Settings → Pages → Source：Deploy from a branch
      → Branch：main、/ (root) → Save

E. 第一次更新
   1. Actions →（如見到 enable 掣先撳）→ 每日蟲害新聞更新 → Run workflow
   2. 等約 3-5 分鐘，見到綠色 ✅
   3. 打開網站（Ctrl+F5）：
      https://peterusingai1222-cloud.github.io/hk-pest-news/

F. 檢查
   https://peterusingai1222-cloud.github.io/hk-pest-news/data/last_run.json
   - fetched：抓到幾多則
   - kept：通過篩選幾多則
   - diagnosis：剔除原因統計
   - samples：新聞標題同結果
   如仍然 0 則，截圖 last_run.json 畀 Copilot。

之後每日香港時間 06:00、13:00、19:00 自動更新。
